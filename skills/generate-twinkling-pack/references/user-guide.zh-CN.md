# 制卡 Skill 使用帮助

新版 `generate-twinkling-pack` 把资料整理成一份多卡 `.winkmd`，有图片或录音时交付 ZIP。需要支持 `.winkmd` 导入的新版闪卡 App。旧 `.wink` 继续能导入；这套 Skill 不再生成旧正文。

可处理文字、笔记、网页、PDF 和图片；扫描件需要运行环境具备 OCR。卡片可以混合正反面问答、挖空和选择题，支持层级分类、星标、提示折叠、翻译跳过朗读，以及普通图片和已有音频文件。本版新建卡不制作图片挖空；改已有文稿时可保留其 `.rimg` 文件。

## 安装与更新

从发布包解压完整目录，放进 AI 工具的 Skills 目录。Codex 默认位置是 `~/.codex/skills/generate-twinkling-pack/`。保留 scripts、references 等全部文件；更新后新建会话，让工具重新发现 Skill。不能只复制 SKILL.md。

## 示例请求

```text
使用 $generate-twinkling-pack，把这份资料制成约 40 张闪卡。
按目录建立层级分类，每张卡考一个知识点；翻译跳过朗读，提示默认折叠。
最后生成并校验 .winkmd；有附件就打成 ZIP。
```

```text
使用 $generate-twinkling-pack，把这些知识点整理成问答和选择题。
重要卡加星；用“医学 → 循环系统”分类；新建卡包时启用输入填空。
```

## 导入

纯文字文件可以在“文件”App 点开 `.winkmd`，也可在闪卡内选择“导入闪卡文件”。带附件 ZIP 从闪卡内的这个入口选。确认后选择已有普通卡包，或点“＋”新建；建议名称会预填。原文写的分类会自动建立或匹配，无分类的卡留在无分类。

`category: ["医学","循环系统"]` 是“医学下的循环系统”这一条路径，每张卡只归最末一级，不代表两种分类。导入已有包时不改包名、分类原有颜色或整个包的填空偏好。

如果缺图，App 原位显示图片不存在；缺录音，去掉对应音频条；结果会列出卡号和文件名。Skill 应在交付前修好缺附件，不把这种恢复行为当成正常交付。

单词卡仍用独立的 `generate-twinkling-word-pack`，格式与流程沿用它自己的说明。
