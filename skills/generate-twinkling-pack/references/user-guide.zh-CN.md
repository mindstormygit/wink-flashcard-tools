# 制卡 Skill 使用帮助

`generate-twinkling-pack` 是“闪卡（WinkNotes）”统一的制卡 Skill，同时支持制作**笔记／选择题卡**和**原生单词卡**：

- **笔记与选择题（`.winkmd`，带图片或录音时为 ZIP）**：支持问答、挖空、单选／多选选择题（含单题 `shuffle` 开关与题内 `:::explanation` 解析）、层级分类、星标、提示折叠、翻译跳过朗读、公式、表格、普通图片和录音。`.winkmd` 导入的正式版目标为闪卡 3.0（2.21.0 公测版按具体构建判断是否已支持 `shuffle` 与题内解析；更早的 v2 构建可用裸 `:::choice` 并将单题解析放在卡背）。本版新建卡不制作图片挖空，改已有文稿时可保留其 `.rimg`。
- **原生单词卡与单词卡包（`.wink`）**：支持英语、日语、韩语、德语、法语、西班牙语、葡萄牙语、意大利语的原生 `WordDocument` 单词卡，包含音标／读音、中文释义、例句与翻译、语言模板字段（音节、假名、罗马音、音调、冠词、复数形式等）以及可选层级分类。词条由当前所选 AI 编写，不调用私有服务或外部词典 API。

> 闪卡目前不支持把笔记卡和原生单词卡放在同一个卡包里。每种受支持的词汇语言会各交付一份 `.wink`；只有同时要求制作笔记或选择题时，才会额外交付一份 `.winkmd`（或媒体 ZIP）。若需制作这八种语言之外的词表（如俄语），Skill 会先征得你同意再转为普通 `.winkmd` 问答卡。

## 安装与升级

从发布包下载 `generate-twinkling-pack.zip`，解压完整目录到 AI 工具的 Skills 目录。Codex 默认位置是：

```text
~/.codex/skills/generate-twinkling-pack/
```

保留 `scripts`、`references`、`agents` 等全部文件，不要只复制 `SKILL.md`；更新后新建会话以重新发现 Skill。

如果你以前单独装过旧版 `generate-twinkling-word-pack`，请按以下顺序迁移：
1. 安装完整的新版 `generate-twinkling-pack/` 目录；
2. 将保存的 `$generate-twinkling-word-pack` 提示词、自动化指令或硬编码脚本路径更新为 `$generate-twinkling-pack` 与 `generate-twinkling-pack/`；
3. 移出旧的 `generate-twinkling-word-pack/` 目录，避免同时命中两个词卡 Skill；
4. 新建会话，用一个词卡请求确认正常工作。

## 示例请求

### 笔记、挖空与选择题

```text
使用 $generate-twinkling-pack，把这份资料制成约 40 张闪卡。
按目录建立层级分类，每张卡考一个知识点；翻译跳过朗读，提示默认折叠。
最后生成并校验 .winkmd；有附件就打成 ZIP。
```

```text
使用 $generate-twinkling-pack，把这些知识点整理成问答和选择题。
重要卡加星，选择题附题内解析；用“医学 → 循环系统”分类；新建卡包时启用输入填空。
```

### 原生单词卡与单词卡包

```text
使用 $generate-twinkling-pack，把下面 30 个英语单词生成一个 .wink 单词卡包。
释义使用简洁中文并保留词性，每个词添加一个自然例句和翻译；音标没有把握时不要猜。
```

```text
使用 $generate-twinkling-pack 分析这个 PDF 的第 3 章，
挑选约 40 个值得学习的英语单词或固定搭配，按小节建立分类，
生成可导入“闪卡”App 的 .wink 单词卡包。
```

```text
使用 $generate-twinkling-pack，把 resilient 制作成一张 .wink 独立单词卡。
添加简洁中文释义、一个自然例句和翻译，不要生成卡包。
```

说明：
- 每个 `.wink` 单词文件只包含一种语言；多种语言会拆成多个文件。
- 未指定独立卡还是卡包时，最终 1 个词导出独立单词卡（不含包名和分类，导入时选目标包），2 个及以上导出单词卡包；明确要求卡包时，1 个词也导出卡包。
- 音标、音调、罕见义项没把握时会留空或跳过并向你报告，不硬猜。

## 导入

- **纯文字 `.winkmd` 和 `.wink`**：可在“文件”App 直接用闪卡打开，或在闪卡内选择「导入 → 闪卡文件」。
- **带 `media/` 的 ZIP**：在闪卡内选择「导入 → 闪卡文件」。
- `.winkmd` 导入时可选已有普通卡包或新建卡包（建议包名会预填）；`category: ["医学","循环系统"]` 表示“医学 → 循环系统”这一条路径，每张卡归最末一级。导入已有包时不改原包名、分类颜色或填空偏好。
- 如果 `.winkmd` 缺图，App 原位显示占位；缺录音会去掉对应音频条，并列出卡号和文件名。Skill 会在交付前检查并修好缺失附件。
