# Security Policy

Please do not publish security vulnerabilities, private card-pack data, credentials, or sensitive source material in a public issue.

Report security concerns privately to `winkcard@qq.com` with:

- the affected script or format component;
- the observed behavior and impact;
- a minimal reproduction that contains no private user data;
- any suggested mitigation.

Generated `.wink` files are unencrypted ZIP containers. Users should treat them as ordinary readable files and avoid sharing packs that contain confidential information.
